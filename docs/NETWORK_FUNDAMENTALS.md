# Network Fundamentals

- **IP address:** identifier assigned to a network interface.
- **CIDR:** notation combining an address and network prefix, such as `192.168.1.0/24`.
- **Port:** transport-layer endpoint number; a listening port alone does not prove a vulnerability.
- **TCP state:** Nmap may report open, closed, or filtered based on observations and controls.
- **Service detection:** probes a reachable port to infer service/product/version; results can be incomplete.
- **Host discovery:** identifies systems responding to selected probes; firewalls may hide live systems.

Use the subnet command for bounded private lab ranges. Never assume a network is authorized merely because it is private.
